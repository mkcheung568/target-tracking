# Security Policy

## Scope

Target Tracking is a browser-local MVP. It has no backend, authentication, database, or server-side user data at this time.

## Reporting a vulnerability

Please report suspected security issues privately through the `mkcheung568` GitHub profile or GitHub Security Advisories when enabled. Do not publish credentials, private JSON backups, browser storage exports, or exploit details in a public issue.

Include:

- a short description of the problem;
- affected page, browser, and version;
- reproducible steps;
- the possible impact; and
- a minimal proof of concept when safe.

We will acknowledge a report when possible, investigate it, and coordinate a fix or public disclosure. Please allow reasonable time for a fix before public disclosure.

## User data guidance

The app stores goals and check-ins in localStorage. Users should export backups carefully and avoid placing secrets or sensitive personal information in goals, notes, or issue reports.
