# Changelog

All notable changes to Target Tracking are documented here.

## [1.0.0] - 2026-09-14

### Added

- Local-first goal dashboard with Today, Goals, Goal Detail, History, Analytics, and Settings views.
- Goal CRUD, pause and lifecycle states with date and frequency scheduling.
- Completed, failed, and skipped daily check-ins with same-day editing.
- Net Score, Completion Rate, Time Progress, Streak, Best Streak, and health indicators.
- Seven/30-day trends, check-in history, heatmap, rewards, language selection, browser reminders, and JSON backup.
- Responsive desktop sidebar and mobile bottom navigation.
